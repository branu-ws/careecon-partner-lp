BRANU AXIS（ブラニュー アクシス）とは、BRANUが2026年9月11日に発表した、中小建設企業の建設AX（AI Transformation）を推進するAI戦略プロジェクトです。建設AIコア「BRANU BRAIN」と、建設AXプラットフォーム「CAREECON Platform」を軸に、DXで蓄積したデータを活用して、業務プロセスや意思決定をAIで変えていくことを目指しています。

この記事では、BRANU AXISの内容を、BRANUの公開情報にもとづいて整理します。建設AXそのものの考え方は、[建設AXとは？DXとの違いと、中小建設会社が取り組むときの考え方](../what-is-construction-ax/)で紹介しています。

## BRANU AXISの概要

BRANU AXISは、建設AIコアと建設AXプラットフォームを軸に、プロダクト開発、研究開発、活用支援、外部連携を一体で進めるAI戦略プロジェクトです。対象は、中小建設企業です。現場の支援から、経営、企業間の連携まで、段階的に進化させていくとしています。

BRANUは17年以上、建設業の支援に取り組んできました（2026年9月時点・自社調べ）。AXISでは、その中でCAREECON Platformを通じて蓄積してきた建設事業のデータや知見を、AIが理解して活用するための土台として使います。

## 名称に込められた意味

BRANU AXISの名称には、「BRANU」が意味する「新しい」と、「AXIS（軸）」の意味が重ねられています。さらに「AXIS」を「AX IS」と読むことで、「AXとは何か」を示す意味を持たせ、建設業界に新しい軸を打ち立てる意志を込めているとBRANUは説明しています。

## 4つの取り組み

BRANU AXISの取り組みは、プロダクト開発、研究開発、活用支援、外部連携の4つです。それぞれを一体で進め、研究開発の成果をプロダクトに反映し、実際の利用から得られる課題やデータを次の開発に生かすことを目指しています。

| 取り組み | 内容 |
| --- | --- |
| プロダクト開発 | AIエージェントやAIアシスタントなど、AIの機能を開発する |
| 研究開発 | フィジカルAIなど、新しい領域でのAIの活用を研究する |
| 活用支援 | 導入後の定着と、AIの活用をサポートする |
| 外部連携 | 技術やサービスの連携を進める |

## 建設AIコアBRANU BRAINと、CAREECON Platform

BRANU BRAINは、建設事業のデータや知見を蓄積し、AIが業務内容や経営状況を理解するための土台となる建設AIコアです。CAREECON Platformは、建設AXのプラットフォームで、建設事業者向けのマッチングサイト「CAREECON」と、統合型ビジネスツール「CAREECON Plus」で構成されています。

CAREECON Plusは、マーケティング、人材管理、施工管理、経営管理を一つにまとめた建設業向けのツールです。AIの機能は、CAREECON Plusの各機能に取り入れる形で提供されると、BRANUは説明しています。

## BRANU AXISの強み

BRANUは、BRANU AXISの強みとして、「DATA × AI × NETWORK」を挙げています。

- **DATA（建設業に特化したデータ）**：17年以上にわたる建設業向けの支援で蓄積したデータを、BRANU BRAINで活用する
- **AI（エージェンティックAI）**：目的に向けて必要なタスクを組み立て、不足している情報の確認や関係者への働きかけまで、自律的に進めるAI
- **NETWORK（CAREECON NETWORK）**：建設会社同士がつながるネットワークとAIを組み合わせ、協力会社、人員、機材など、企業間のリソースの活用を支援する構想

## 提供されているAIの機能

BRANU AXISの公開ページでは、現在のAIの機能として、特定の業務に特化したAIエージェントと、AIアシスタントが紹介されています。

| AIエージェント | 内容 |
| --- | --- |
| AIブログ | コンテンツの作成を支援する |
| AI日報 | 施工写真をもとに、日報を作成する |
| AI報告書 | AI日報をもとに、報告書を作成する |
| AI工程表 | 見積書をもとに、工程表を作成する |
| AI施工事例 | 画像から、施工事例を作成する |
| AI写真クリーンナップ | 施工写真の不要なものを消す |
| AIメッセージ | 取引先へのメッセージの送付を支援する |

AIアシスタントは、スマートフォンからチャットで指示し、必要なAIエージェントを呼び出して、施工管理データの確認や更新、日報や報告書の作成などを一つの窓口から進められる機能です。AIが作成した内容は、人が確認して使うことが前提です。提供状況や、顧客の運用に合うかどうかは、本部の説明やデモで確認できます。

## 建設AXの進化の4段階

BRANU AXISでは、建設AXの進化を4つの段階で示しています。この中で、現在の段階は最初の段階です。後の段階は今後の方向性で、時期は示されていません。

| 段階 | 内容 |
| --- | --- |
| LEVEL 1 | 写真を起点にした日報の作成やコンテンツの生成など、AIエージェントとAIアシスタントの展開（現在の段階） |
| LEVEL 2 | ゴールから必要なタスクを考え、複数のAIエージェントを組み合わせて、自律的に計画・実行・調整するAI |
| LEVEL 3 | 企業ごとのデータ、過去の実績、判断の基準を理解し、経営判断に必要な情報や選択肢を示す「経営の右腕」となるAI |
| LEVEL 4 | 各社のAIがCAREECONのネットワーク上でつながり、企業を越えた協業やリソースの活用を支援するネットワーク |

## 提案する側のポイント

BRANU AXISは、AIの機能が、CAREECON Plusの各機能と一体で提供される点が特徴です。建設会社へ説明するときは、現在使える機能（LEVEL 1）と、今後の方向性（LEVEL 2以降）を分けて伝えることが大切です。今後の機能は、提供の時期や内容を約束するものとして説明しないようにします。

「日報や報告書の作成に、どれくらい時間がかかっていますか」「工程表は、見積をもとに作っていますか」と聞くと、AIの機能が合うかどうかを話しやすくなります。質問の考え方は[建設業のお客様に何を聞けばいい DX提案につながる5つの質問](../construction-dx-sales-questions/)も参考にしてください。
