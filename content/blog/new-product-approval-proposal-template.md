新しい商材や代理店事業の取り扱いを社内で通すには、「なぜ今やるのか」「どれだけの収益が見込めるか」「どれだけの工数がかかるか」「どんなリスクがあり、どう備えるか」を、判断できる形で示すことが重要です。

この記事では、稟議や提案書の章立てと、各章に書く内容を紹介します。記入欄のある表は、自社の数字を当てはめて使えるようにしています。CAREECON Plusの報酬条件は、資料請求後の個別案内となるため、収益の欄には仮の数字を載せていません。

## 提案書の章立て

| 章 | 書く内容 |
| --- | --- |
| 1 背景・目的 | なぜ新商材を検討するのか（既存顧客への提案の幅、継続的な収益など） |
| 2 市場の状況 | 対象市場の規模や動き |
| 3 商材・提携の概要 | 商材の内容、提携モデル、本部の支援 |
| 4 収益の見込み | 報酬の条件、契約件数の仮定、収益の試算 |
| 5 工数・体制 | 担当者、必要な時間、本業との両立 |
| 6 リスクと対策 | 想定されるリスクと備え |
| 7 進め方・判断期限 | 開始時期、検証期間、見直しの基準 |

## 各章の書き方

### 1 背景・目的

自社の顧客基盤、現在の課題、新商材で実現したいことを、具体的に書きます。「既存顧客への提案の幅を広げたい」「継続的な収益の柱を持ちたい」など、経営者が判断しやすい言葉にします。

### 2 市場の状況

対象市場の規模や成長の見通しを、出典つきで書きます。例として、建設分野のソフトウェア市場は、次のように見込まれています。建築分野の建設テック国内市場規模は、2023年度（推計）の1,845.4億円から、2030年度（予測）には3,042.7億円に拡大し、年平均成長率は7.4%と見込まれています。出典：矢野経済研究所「2025年版 建設DX（ConTech）市場の実態と展望 ～ソフトウェア・ソリューション編～」（2025年3月）、2025年4月17日プレスリリース。ベンダー売上高ベース、土木を除く建築分野のソフトウェア・ソリューション市場で、ハードウェアは対象外です。

### 3 商材・提携の概要

CAREECON Plusは、見積・請求書や案件別の収支などの経営管理と、AI日報・工程表などの施工管理を一つにまとめた建設業向けの統合型ツールです。提携モデルは、紹介型と代理販売型があり、加盟金・初期費用は不要です。本部の支援として、営業資料の提供、営業同行・Web商談支援、勉強会・研修、顧客の初期設定支援、専属コンサルタントによる入力代行サポート、導入後の定着支援、専用相談窓口があります。

### 4 収益の見込み（記入式）

報酬の条件は、資料請求後に個別に案内されます。条件を確認したうえで、次の表に自社の仮定を入れてください。

| 項目 | 記入欄 | 根拠・メモ |
| --- | --- | --- |
| 提案する顧客の数 | | 顧客リストから |
| 契約に至る割合の仮定 | | 他の商材の実績を参考に |
| 契約件数（年） | | |
| 報酬の条件（率・継続条件） | | 提供元に確認 |
| 収益の見込み（年） | | |

数字は、仮定であることを明記し、複数のパターン（控えめ・標準）を示すと、判断しやすくなります。

### 5 工数・体制（記入式）

| 項目 | 記入欄 |
| --- | --- |
| 担当者 | |
| 週あたりの時間（準備・会話・商談） | |
| 本業との調整方法 | |
| 本部の支援で減らせる部分 | |

工数の考え方は[建設業向け代理店の営業工数の見積もり方](../partner-sales-effort-estimate/)も参考にしてください。

### 6 リスクと対策

| リスク | 備えの例 |
| --- | --- |
| 契約が想定どおり取れない | 検証期間を決め、見直しの基準を設定する |
| 営業の時間が足りない | 紹介型から始める、担当者を決める |
| 顧客との関係への影響 | 顧客が困っていないときは提案しない方針を決める |
| 契約後の対応の負担 | 本部と自社の役割分担を、契約前に確認する |

### 7 進め方・判断期限

まず小さく始める場合は、「一定期間で、何社に提案し、何社が関心を示したか」を確認し、続けるかどうかを判断する基準を決めておきます。

## 稟議の前に、提供元へ確認したい質問

1. 報酬の条件と、継続の条件は何か
2. 紹介型と代理販売型で、自社の担当と本部の担当は、どう分かれるか
3. 本部の支援は、どこまで用意されているか
4. 契約後の問い合わせの窓口は、どこか
5. 顧客の情報を共有する場合の、取り扱いはどうなるか

## よくある質問

### 稟議書に、収益の数字は必ず入れる必要がありますか

判断のために、仮定を明記した試算があると、経営者が検討しやすくなります。報酬の条件を確認できていない段階では、確認する旨を書いて、仮定の範囲を示してください。

### 小さく試す場合、何を決めておくべきですか

期間、提案する顧客の数、続けるかどうかの判断基準を決めておきます。
